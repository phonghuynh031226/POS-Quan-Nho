# POS Quán Nhỏ - Frontend

Frontend React + Vite cho hệ thống POS, màn hình pha chế và trang theo dõi đơn hàng của Quán Nhỏ.

## Chạy dự án

```bash
npm install
npm run dev
```

Ứng dụng mặc định chạy tại `http://localhost:5173`.

## Build production

```bash
npm run build
```

## Kết nối backend

Sao chép `.env.example` thành `.env` và chỉnh `VITE_API_BASE_URL` nếu backend không chạy tại `http://localhost:8080/api`.
